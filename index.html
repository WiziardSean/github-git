Getting Started

What software do I need to install before the workshop? +

You should have the following tools installed on your computer:

  • Git: Installed from git-scm.com.
  • Code Editor: VS Code or VSCodium.
  • GitHub Account: A free account registered on github.com.
Is prior coding experience required to join the Software Engineering Society? +

Not at all! We welcome students of all skill levels across all degree programs at Pan Africa Christian University. Our sessions range from fundamental beginner tracks to advanced software architecture workshops.

Git & GitHub Workflow

What is the difference between Git and GitHub? +

Git is a local command-line tool that tracks version history and changes in your code repository. GitHub is a web-based cloud platform that hosts your Git repositories, enabling collaboration, code review, and cloud deployments.

How do I fix a "Permission denied (publickey)" error when pushing? +

This occurs when GitHub cannot authenticate your computer. You can resolve it by either:

  1. Generating an SSH key (`ssh-keygen`) and adding it to your GitHub Account Settings under SSH and GPG keys.
  2. Switching your remote URL to HTTPS mode using git remote set-url origin https://github.com/USERNAME/REPO.git and authenticating via browser/Personal Access Token.
How do I update my local repo after changes are made on GitHub? +

Run the pull command in your terminal inside your project directory:

git pull origin main

This fetches and merges the latest changes from the remote repository into your local branch.

Cloud Deployment

Should I use Vercel or Netlify for my project? +

Both services offer free tiers with continuous integration from GitHub:

  • Vercel: Best suited for modern JavaScript frameworks like Next.js, React, and Vite applications.
  • Netlify: Ideal for static HTML/CSS/JS websites, drag-and-drop quick deploys, and form handling.
Will my live site automatically update when I push code to GitHub? +

Yes! Once you link your GitHub repository to Vercel or Netlify, every new commit pushed to the main branch triggers an automatic cloud build and deployment.

Club Governance & Operations

How is the club's budget administered? +

The Software Engineering Society operates under an institutional semester allocation from Pan Africa Christian University. All expense requisitions require joint dual authorization from the Treasurer and the Faculty Patron.

How can I obtain a copy of the official SES Constitution? +

The official constitution is available upon request through the club Secretary or via our official document archive provided during general meetings.
